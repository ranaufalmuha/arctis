# Strict Grid

## Core Rule
- Use a strict 8px modular grid for all spacing.
- All margins, paddings, and gaps must be multiples of 8px.
- Use 8px, 16px, 24px, 32px, 48px, 64px spacing scale.
- Never use arbitrary spacing values outside the 8px grid.

## When to apply
- Always. This is a global layout constraint.
