# Hairline Borders

## Core Rule
- Use 1px solid borders on all containers, cards, panels, and dividers.
- Use `rgba(255,255,255,0.15)` for light borders on dark backgrounds.
- Use `rgba(0,0,0,0.12)` for light borders on light backgrounds.
- Never use borders thicker than 1px for layout elements.

## When to apply
- Always. This is a global visual constraint.
