# Custom Cursor

## Core Rules
- Replace the default browser cursor with a custom follower element.
- Track mouse position via mousemove event listener.
- Use requestAnimationFrame for smooth rendering.
- Apply a subtle scale effect on hover over interactive elements.
- Use CSS transitions for hover state changes.
- Support reduced-motion preferences.

## Avoid
- Blocking the main thread with complex cursor logic
- Large cursor elements that obstruct content
